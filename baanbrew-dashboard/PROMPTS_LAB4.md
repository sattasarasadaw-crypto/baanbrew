**4.1A ฟังก์ชัน**
```
ใน src/lib/analytics/rfm.js มีฟังก์ชันที่ยังว่าง: percentileScores, segmentOf, computeRfm

ตรวจ: เปิด `http://localhost:5173/?demo` แท็บ **ลูกค้า & เมนู** ต้องเห็น Champions 455 คน ทำยอด 39%

**4.1B เจาะดูรายชื่อ (vibe coding หน้าจอ)**
```
ใน src/lab4/CustomersTab.jsx มีตัวแปร picked เก็บกลุ่มที่ผู้ใช้คลิก
ทำให้คลิกแท่งในกราฟ RFM หรือแถวในตารางแล้วแสดงการ์ดรายชื่อลูกค้าในกลุ่มนั้น
- เรียงตามยอดซื้อรวมมากไปน้อย แสดง 15 คนแรก: รหัส, ไม่ได้มากี่วัน, จำนวนบิล, ยอดซื้อ, คะแนน R-F-M
- ปุ่ม "ดาวน์โหลด CSV" ทั้งกลุ่ม ใส่ BOM ให้ Excel อ่านภาษาไทยได้
- ปุ่มปิด และไฮไลต์แถวของกลุ่มที่เลือกในตาราง
- คลิกกลุ่มเดิมซ้ำ = ปิด
```
ตรวจ: ดาวน์โหลด CSV กลุ่มชั้นยอด ต้องได้ 455 แถว

## Lab 4.3 · รีวิวและ merge

```
รีวิวการเปลี่ยนแปลงทั้งหมดของ branch นี้เทียบกับ main (git diff main...HEAD)
ในฐานะผู้ตรวจที่เข้มงวด ตรวจ:
1. มีไฟล์ test ถูกแก้ไหม
2. มีที่ไหนอ่าน collection sales ทั้งหมดจากหน้าเว็บไหม
3. มีการใช้ toISOString กับวันที่ไทยไหม
4. มี secret หรือ key หลุดเข้า commit ไหม
5. ข้อมูลลูกค้าที่ดาวน์โหลดได้ ควรมีคำเตือนเรื่อง PDPA ไหม
รายงานเป็นตาราง ข้อ / ผล / ไฟล์และบรรทัด ยังไม่ต้องแก้
```

**เขียนคำอธิบาย PR จากผลวิเคราะห์จริง**
```
รัน npm run analytics:dry แล้วใช้ตัวเลขที่ได้ เขียนคำอธิบาย PR ภาษาไทย
หัวข้อ: สิ่งที่เพิ่ม · ข้อค้นพบ 3 ข้อสำหรับเจ้าของร้าน (ตัวเลขจริงจากผลลัพธ์ ห้ามแต่ง) · วิธีทดสอบบน Preview
แล้วอัปเดต PR ด้วย gh pr edit (หรือให้ข้อความมาฉันวางเอง)

## Lab 4.6 · pipeline อัตโนมัติด้วย GitHub Actions

```
อธิบาย .github/workflows/analytics.yml ทีละส่วนเป็นภาษาไทย:
ทำงานเมื่อไร (เวลาไทย), ใช้ secret อะไร, ถ้า test ไม่ผ่านจะเกิดอะไรขึ้น

```

**ถ้า Action ล้ม** คัดลอก log ส่วนที่แดงมาให้ Claude:
```
GitHub Action "Build analytics" ล้ม นี่คือ log: [วาง log]
ช่วยหาสาเหตุก่อนแก้ ถ้าเป็นเรื่อง secret ให้บอกวิธีแก้บนเว็บ ห้ามขอให้ฉันส่ง key มา
```
